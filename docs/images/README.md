# CloudLab Screenshots Directory

Place your actual deployment screenshots in this directory with the following filenames:

1. `terraform_apply_output.png` - Screenshot of your terminal running `terraform apply` successfully.
2. `aws_console_resources.png` - Screenshot of your AWS Management Console showing provisioned EC2 / RDS / Secrets Manager resources.
3. `alb_response.png` - Screenshot of your browser accessing `http://<alb-dns-name>` showing the 200 OK application response.
